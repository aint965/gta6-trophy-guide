An unofficial offline GTA VI trophy guide and tracker for PlayStation 5. All 55 trophies have original, cited guidance. The roadmap puts the Chapter 1 meditation warning first and distinguishes trophy milestones from the game's 100% checklist.

Run `node serve.ts` with Node.js 22.18 or later and open `http://localhost:8080` in desktop Chrome. The guide loads from local files. Progress and story spoiler preferences are stored in the browser; use **Export** to back them up or **Import** to restore a backup.

For the make.fun dossier, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
